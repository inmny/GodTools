# 世界脚本

从「GodTools → 世界 → 世界脚本」添加规则。选好触发时机、作用对象和执行步骤后，可以先预览会命中的对象，再启用规则。实际结果在「运行记录」查看。

## 剧本

在「世界脚本 → 剧本」新建或查看剧本，通过脚本的「更多 → 移入剧本」组织相关规则。「添加脚本 → 战后重建」会创建发起重建、发放物资和到期复查三条草稿。实际使用时启用发起和复查脚本，发放物资可以手动运行。

从剧本总览导出时可以设置版本号和导入页公开的共享参数。导入同一个剧本标识的较新版本时，可查看规则变化并确认升级。更新的脚本以停用草稿安装，继承当前对象绑定、进度和待办。新版移除的包脚本会停用留档。

自动执行在脚本之间分帧。未开启分批的脚本按自己的动作预算运行完当前轮次。剧本相关的易主、王位、战争结束和阈值事件，以及延时复查，会随世界存档保存。

## 区域、分批与试运行

「世界脚本 → 地图区域」可用地图上的两个对角定义矩形。「区域内村庄」「在区域有村庄的王国」和「区域内地块」可作为查询。剧本包按名称重新绑定区域，目标世界可以画出自己的边界。

对主查询逐项执行的独立步骤，可在高级设置指定每批目标数。任务按步骤顺序处理同一批初始目标，存档包含目标名单和续跑位置。使用前先应用脚本修改。任务期间改动规则或共享参数会停止旧任务，执行记录会显示结果。每批已完成的写入随地图保存。

从脚本的「更多」、剧本总览或升级预览创建试运行副本。每次打开「已保存规则」或「草稿规则」都从同一份初始地图复制一份工作地图。两边重现同一事件、运行到同一世界时间，再分别点「记录结果」，即可比较处理目标、待办和有关资源的实际库存。

使用独立 WorldBox 和 DebugToolbox 运行 [Rehearsal](../Tests/WorldScript/Rehearsal.csx) 可重复验证重建与救济同时补给的场景。初始库存为 5，重建发放 10，救济继续加 10 时结果为 25，救济改为补到 10 时结果为 15。两边各保留一个复查待办。

## 剧情场次与补拍

从「世界脚本 → 剧本」打开场次。场次可手动开始、到指定世界年自动开始、提醒或暂停。开场可以运行当前剧本的一条手动脚本。到年暂停时，作者点「开始场次」才运行开场脚本。

在「场次设置」选出演人物和取景地。选择村庄内的地块会绑定当时的村庄和王国，可记录人物阵亡、村庄易主和新王登基首次发生时的地点和结果。展开拍摄标记可以定位或跟拍。干净取景可以用原版「隐藏界面」快捷键退出，默认是 H。

每个检查点保存当前世界状态与镜头，事件标记可以提供取景地点。打开检查点会载入一份暂停的工作副本，保留原检查点。「选为正片结尾」会在列表置顶该检查点。

「添加脚本 → 百年试炼后的王位交替」提供两个场次。绑定守关人及取景地后，在开场前保存共同起点，再从两份工作副本分别演练存活和阵亡继位。可用隔离 WorldBox 和 DebugToolbox 运行 [CentennialTrial](../Tests/WorldScript/CentennialTrial.csx) 验证。
