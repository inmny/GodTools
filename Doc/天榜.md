# 天榜

在「GodTools → 生物 → 天榜」打开榜单。左栏可以切换人物、装备、王国、城市、联盟、军队、文化、氏族、家庭、语言、亚种、宗教、战争和谋划。人物条目使用原版头像，点击可查看人物信息。王国等条目使用原版旗帜，可打开对应详情，有可用地点时可以定位。

## 排序、筛选和显示

- 「排序」里点击图标添加关键词，第一项决定主排序。每一项可以独立设置升降序，通过上下按钮改变优先级。「恢复默认排序」会恢复该榜单初始的关键词和顺序。
- 「筛选」可以按名称、王国、文化、氏族、语言、亚种、城市、宗教、生物类型和特质等字段设置条件。归属用旗帜选，生物类型用原版图标选，特质按原版分组。可搜索选项，并用「与」「或」「非」及括号组合条件。点条件牌能移动编辑光标。先预览命中数量，再应用筛选。
- 「行内容」可以设置头像或旗帜、名次、固定列和自动补列。表格先显示主排序和次排序字段，有空间时再插入固定列和默认字段。两侧栏可独立收放，表格会跟着调整可见列。
- 窗口外右侧的分布图显示主排序字段在当前结果中的分布。数值按频数或区间展示，无序类别按数量展示，品阶按声明的顺序展示。顶栏图标可切换分布图。
- 顶栏的名次输入框可直接跳转，两旁按钮可到顶或到底。从详情返回时可以继续浏览原来的位置。

「参排范围」决定哪些条目参与排名，「显示筛选」可以在分配名次后进一步缩小结果。主指标为零的条目正常排名，主指标缺值的条目显示「未排名」。所有排序关键词都相等时并列，例如第 1、第 1、第 3。

## 预设、总览和榜单记录

在「预设」里保存排序、筛选和行内容。点击预设名会应用整套配置，悬停可以查看配置摘要。可以更新、重命名或删除预设，配置随世界存档保存。

点击预设右侧的星星，榜单总览就会显示一张卡片。卡片可调整展示的名次数量，点击能打开对应的预设。总览优先展示已保存的结果，手动刷新只读取收藏涉及的榜单来源。

使用「保存本次排名」保存当前显示的条目、名次和分数。记录随世界存档保存，可从总览的「最近记录」或左栏的「榜单记录」打开。使用同一套榜单、排序和筛选条件的两份记录可以对比。

## 战力和峰值记录

人物榜默认按「战力」排列。战力按固定的近战、远程和重甲对手试算 32 秒，取三个对照的中位数。基准强度每提高十倍增加 100 分。悬停分数可查看各分项以及已计入的技能和触发次数。

「战力峰值记录」从榜单刷新的样本里保留最高分数及对应的角色数据和像素头像，最多保留 100 个角色。点条目末尾的放置按钮，可将当时的角色放回地图。有旧版记录的存档还可以在「旧战力峰值记录」里查看和放置。旧基础战力的数值筛选条件需按现行分数重新设置。

## 其他模组

安装相应模组后，人物榜可以使用它提供的境界等指标，排序和筛选图标按注册来源分组。已接入天榜的 Cultiway 提供功法榜、魔网法术榜、地区榜、法宝榜、材料榜和符箓榜，可从对应条目进入 Cultiway 的详情。模组主动注册时优先使用它的定义。[模组接入](模组接入.md#注册天榜)
